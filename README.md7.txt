Student Information Dictionary

Project Description

This project is created using Python to store and manage student information using a dictionary. It allows users to display student details, search for a student, add new student records, and update existing information.

Objective

The main objective of this project is to understand Python dictionaries and learn how to manage student records using key-value pairs.

Technologies Used

- Python
- Jupyter Notebook

Features

- Store student details such as ID, name, age, course, and marks.
- Display all student records.
- Search for a student using their ID.
- Add new student details.
- Update existing student information.
- Check whether a student ID already exists.

How It Works

1. Student details are stored in a Python dictionary.
2. Each student is identified by a unique student ID.
3. The search function displays the details of a selected student.
4. The add function creates a new student record.
5. The update function modifies an existing student's information.
6. Finally, all student records are displayed with the updated details.

Sample Output

Search Operation:
Student details found: {'name': 'Kiran', 'age': 23, 'course': 'MCA', 'marks': 85}

Add Operation:
New student added successfully.

Update Operation:
Student details updated successfully.
